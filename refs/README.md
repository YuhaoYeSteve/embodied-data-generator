# 示例素材

`reference_board.png` 是本项目用几何图形绘制的虚构物品布局板，不含客户截图、个人资料或外部图片。它只用于演示参考图片绑定，不代表真实机器人采集的数据。

图片及其说明通过 `studio_references.py` 注册，模板将图片绑定到指定分段。新增自己的图片时，请同时更新注册信息和分段绑定；个人素材和授权记录应保存在本地，不要提交到公共仓库。

`manifest.example.json` 是旧版 `pipeline_30s.py` 的自备素材路径配置示例。将其复制为 Git 忽略的 `manifest.json` 后填写自己的素材路径，并另行保存来源与授权信息；项目不附带人物或场景照片。
